# Kaynaklar

Ana kayıt: `config/sources/sources.yaml`.

Kaynaklar dört statüde tutulur:

- CORE
- SUPPORTING
- RESEARCH_CANDIDATE
- STANDARD_VALIDATION

Bu sayfa ilerleyen fazda registry'den otomatik üretilecektir. Faz 0 paketi, seçilmiş kaynakların kimliklerini ve kullanan modülleri registry içinde içerir.
